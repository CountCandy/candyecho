🔌 Use CandyEcho as a TTS backend (SillyTavern & other apps)

CandyEcho exposes an OpenAI-compatible speech endpoint, so anything that speaks the OpenAI TTS API can use it as a backend.

Base URL http://localhost:8100 · Endpoint POST /v1/audio/speech

SillyTavern

  1. Open Extensions → TTS and set TTS Provider to OpenAI Compatible (click Reload if the fields don't appear).
  2. Provider Endpoint: http://localhost:8100/v1/audio/speech
  3. Model: candyecho  ·  API Key: not-needed
  4. Available Voices: enter your voice names from the list above (comma-separated), then map characters to them.

Raw API

curl -X POST http://localhost:8100/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d "{\"input\":\"Hello from CandyEcho!\",\"voice\":\"YOUR_VOICE\",\"response_format\":\"wav\"}" \
  --output out.wav

response_format: wav (default), mp3, flac, ogg. List voices at GET /v1/audio/voices. model and speed are accepted for compatibility but ignored.

Running SillyTavern on another machine? Start CandyEcho with --host 0.0.0.0 and use this PC's LAN IP in the URL instead of localhost.
